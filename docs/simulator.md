# x2模拟器（单文件便携版）

**中文** | [English](simulator.en.md) | [Français](simulator.fr.md)

双击运行 [x2模拟器.exe](../exe/x2模拟器.exe) 即可启动机器人网关：机器人出现在窗口中（调试面板默认隐藏，按 **F1** 呼出），开始监听 `127.0.0.1:9002` 等 Agent 接入（接入方式见 [Agent 说明](../example/README.md)）。示例 Agent 连上后会下发开场白。

文件大小为 **66,880,000 字节（66.88 MB）**，可以只分发这一个 EXE，无需附带 Data 文件夹、Playground 或 Python。需要语音对话时，Python Agent 仍需单独启动；此 EXE 不包含其 API Key 或配置。

## 运行须知

| 项 | 值 |
|---|---|
| 系统 | Windows 10/11 x64 |
| 硬件 | 麦克风（说话）+ 扬声器（播放） |
| 监听 | `127.0.0.1:9002`（仅本机；跨机访问见下方"改配置"） |
| 路径 | `/api/V1/open-portal/app/wss/agent-sdk` |
| 鉴权 | 示例客户端发送 HMAC 签名；网关是否强制校验由其构建配置决定 |

- 测试语音时保持窗口打开；若最小化后出现音频或网络异常，先恢复窗口再排查
- **F1** 呼出/隐藏调试面板（默认隐藏，录屏时画面干净）
- 调试面板按钮可手动触发挥手/表情/行走（无 Agent 时验证动作用）
- 同一时间只允许一个 Agent 连接；Agent 退出后可立即重连

## 首次启动与缓存

无需安装 Unity、手动解压或执行配置向导。首次运行会静默释放完整的 Unity 运行库和资源到 `%LOCALAPPDATA%\x2sim\<版本标识>`，后续运行复用缓存；这是单文件分发，运行时仍需要磁盘资源。

缓存约 328 MiB，首次准备建议至少留出 500 MB 空间。本机首次打开窗口约 12.6 秒，后续约 1.8 秒。退出模拟器后可删除缓存，下次启动会自动生成。Unity 的日志和用户偏好仍按原程序方式保存。

本包保留全部 207 个原始构建文件，包含此前修复的调试台 DLL。

## 重新打包（可选）

打包资料独立存放在仓库父级的 `x2-simulator/`，不包含在此仓库内。该目录包含 `build-portable.ps1`、启动器源码、7-Zip 工具、`unity-payload.7z` 固化资源和 SHA-256 清单。

在独立打包目录运行：

```powershell
.\build-portable.ps1
```

输出为 `dist/x2模拟器.exe`，默认不需要原始 Unity 工程或 Playground。要更新固化资源，可传入 `-Source '新的完整Unity构建目录'`。打包脚本验证压缩包并限制最终 EXE 小于 100,000,000 字节。

## 改配置（可选）

本次交付基于现有 Unity 构建，未附带完整 Unity 工程。单文件打包脚本负责封装已有构建，不会改变监听地址或鉴权行为。若需修改这些行为，需要先获得修改后的 Unity 构建，再更新固化资源并重新打包。
